# Web Research AI Agent

This project is a personal AI research assistant that searches the web, gathers source content, and generates a polished markdown digest using a local Ollama model. It is inspired by the approach of building a web research agent with Ollama and Qwen.

## Why this project exists

The goal is to create a lightweight local workflow for research tasks without relying on a paid hosted API. With this setup, you can:

- research a topic from live web sources
- summarize findings into a structured markdown digest
- keep the workflow private and local
- avoid per-query API costs

This makes it useful for everyday tasks such as news summaries, competitor research, product comparisons, and briefing notes.

## What the script does

When you run the program, it performs the following steps:

1. Prompts you for a research question.
2. Calls the Ollama web search API to find relevant pages.
3. Downloads and cleans the text from each result page.
4. Sends the collected context to a local LLM.
5. Saves the generated summary as a timestamped markdown file.

## Project structure

- [research_agent.py](research_agent.py) — Main application logic.
- [requirements.txt](requirements.txt) — Python dependencies.
- [digest_*.md](digest_20260727_213014.md) — Example output files generated by the tool.

## How it works

### 1. Search stage
The function `search_web(query)` sends a query to the Ollama web search endpoint and returns a list of top results.

### 2. Retrieval stage
The function `fetch_text(url)` opens each page, removes boilerplate HTML such as scripts, styles, nav, and footer sections, and extracts the readable text.

### 3. Synthesis stage
The `main()` function combines:

- your prompt
- the search results
- the extracted page content

and sends everything to the local model for summarization.

### 4. Output stage
The model response is saved as a markdown file such as:

- `digest_20260727_213014.md`

## Prerequisites

Before using the project, make sure you have:

- Python 3.8 or newer
- Ollama installed and running locally
- an Ollama API key available through the `OLLAMA_API_KEY` environment variable
- a compatible local model available, such as `qwen3.5:4b`

## Installation

### 1. Install Python dependencies

```bash
pip install -r requirements.txt
```

### 2. Pull the model

```bash
ollama pull qwen3.5:4b
```

If your machine has limited RAM, you can try a smaller model such as `qwen3.5:0.8b`.

### 3. Set your API key

On Windows PowerShell:

```powershell
$env:OLLAMA_API_KEY="your_api_key_here"
```

On macOS or Linux:

```bash
export OLLAMA_API_KEY="your_api_key_here"
```

## Run the agent

```bash
python research_agent.py
```

Example prompt:

```text
Enter your research prompt: Latest trends in AI coding assistants
```

The script will fetch relevant sources, build a digest, and save it as a markdown file in the project folder.

## Example use cases

This project is useful for:

- market research and competitor tracking
- summarizing recent developments in a topic
- preparing briefing notes for meetings
- comparing tools, products, or frameworks
- generating a daily digest from current web content

## Tips for better results

- Ask for a clear output structure, such as headings, bullets, and a short conclusion.
- Use specific prompts when you want a narrow summary.
- Spot-check the generated output against the original sources, especially for factual claims.
- If results are weak, try a more specific question or a different model.

## Example output shape

```md

## Sources

- Source B
```

## Troubleshooting

### Missing API key
If you see an error about the API key, make sure `OLLAMA_API_KEY` is set correctly in your terminal session.

### Model not found
If the model cannot be loaded, confirm that it has been pulled locally:

```bash
ollama list
```

### Empty or weak summaries
This can happen if:

- the websites are hard to scrape
- the content is blocked or poorly formatted
- the search results are not closely related to your prompt

### Network issues
The script depends on access to the Ollama web search service and the websites it fetches.

## Limitations

- The quality of the output depends heavily on the quality of the retrieved web pages.
- Some websites may block scraping or return content that is difficult to parse.
- Smaller local models may miss details or produce less polished summaries than larger hosted models.
- The project is intentionally simple and does not yet include advanced agent features like retries, memory, or multi-step planning.

## How to customize it

You can adjust the behavior by changing:

- `MODEL` in [research_agent.py](research_agent.py) to use a different local model
- `SEARCH_URL` if you want to change the search endpoint
- the number of results returned by `search_web(query)`
- the content cleaning rules in `fetch_text(url)`
- the summarization prompt in `main()` for different output styles
