# Web Research AI Agent

This project is a lightweight research assistant that searches the web, collects relevant page content, and generates a markdown research digest using a local Ollama model. It is designed for quick, prompt-driven research tasks such as summarizing a topic, comparing products, or gathering context from multiple sources.

## What the project does

The script performs the following steps:

1. Accepts a research prompt from the user.
2. Calls the Ollama web search API to find relevant web pages.
3. Downloads and cleans the content of each result page.
4. Sends the collected information to a local LLM model.
5. Saves the generated research summary as a markdown file with a timestamp.

## Project files

- [research_agent.py](research_agent.py) — Main application logic.
- [requirements.txt](requirements.txt) — Python dependencies.
- [digest_*.md](digest_20260727_213014.md) — Output files generated by the script.

## How it works

### 1. Web search
The function `search_web(query)` sends a query to the Ollama web search endpoint and returns a list of search results.

### 2. Page content extraction
The function `fetch_text(url)` retrieves a page, removes non-essential HTML elements such as scripts, styles, nav, and footer blocks, and extracts readable text.

### 3. Research synthesis
The `main()` function combines the user prompt, search results, and extracted page text into a single prompt and sends it to the Ollama model. The model then returns a markdown summary.

### 4. Output generation
The generated digest is written to a file named like:

- `digest_20260727_213014.md`

## Setup

### Prerequisites

- Python 3.8+
- An Ollama API key set in the environment as `OLLAMA_API_KEY`
- A compatible Ollama model available locally

### Install dependencies

```bash
pip install -r requirements.txt
```

### Pull a model

If you are using the default configuration, make sure the model is available:

```bash
ollama pull qwen3.5:4b
```

### Set the API key

On Windows PowerShell:

```powershell
$env:OLLAMA_API_KEY="your_api_key_here"
```

On Linux or macOS:

```bash
export OLLAMA_API_KEY="your_api_key_here"
```

## Run the program

```bash
python research_agent.py
```

You will be prompted to enter a research query, for example:

```text
Enter your research prompt: Latest trends in AI coding assistants
```

The script will then create a markdown digest file in the project folder.

## Example use cases

This tool is useful for:

- Market research and competitor analysis
- Writing summaries of a topic from multiple online sources
- Researching technologies, tools, or frameworks
- Preparing briefing notes before meetings or presentations
- Creating AI-assisted content digests from live web sources

## Notes and limitations

- The tool depends on network access and the availability of the Ollama web search API.
- Some websites may block scraping or return content that is hard to parse.
- The model may occasionally miss details or overgeneralize based on the available sources.
- The generated digest reflects the quality and relevance of the fetched web results.

## How to customize it

You can adjust the behavior by editing:

- `MODEL` in [research_agent.py](research_agent.py) to use a different Ollama model
- `SEARCH_URL` if you want to target a different search endpoint
- the number of results in `search_web(query)`
- the content cleaning logic in `fetch_text(url)`
